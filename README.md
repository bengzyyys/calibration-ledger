# 本地器具校准台账

本机运行的器具校准与证书台账。数据保存在用户指定的本机 JSON 文件中，
不连接任何真实实验室；退出后重新打开同一台账可继续查询与操作，
不同台账文件的数据互不混入。

## 构建

```bash
go build ./...
```

## 测试

```bash
go test ./...
```

## 命令行用法

台账文件通过 `--ledger` 指定，或设置环境变量 `CAL_LEDGER`。

```bash
calibrate --ledger <台账文件> <命令> [参数]
```

| 命令 | 说明 |
| --- | --- |
| `register --id <编号> --name <名称> --allowed-error <允许绝对误差>` | 登记器具（唯一编号，初始为待校准状态） |
| `set-status --id <编号> --state <在用\|停用\|待校准>` | 切换器具状态 |
| `cert-add --instrument <编号> --number <证书编号> --cal-date <YYYY-MM-DD> --expiry <YYYY-MM-DD> --method <方法> --measured-error <测得误差> --summary <摘要>` | 录入校准证书 |
| `use --id <编号>` | 申请使用器具 |
| `check --id <编号>` | 按器具核对 |
| `list` | 列出全部器具 |

示例：

```bash
export CAL_LEDGER=/path/to/ledger.json
calibrate register --id I001 --name 卡尺 --allowed-error 0.05
calibrate cert-add --instrument I001 --number C001 --cal-date 2026-09-01 --expiry 2027-09-01 --method 外校 --measured-error 0.01 --summary 零点示值误差
calibrate set-status --id I001 --state 在用
calibrate use --id I001
calibrate check --id I001
```

## 业务规则要点

- **登记器具**：编号与名称不能留空或只有空白；允许误差必须是有限且不小于零的数；
  编号在台账中唯一，重复或无效填写被明确拒绝，原记录不变；新器具一律为待校准状态。
- **状态切换**：可在用、停用、待校准之间切换；切换为在用本身不代表已经校准；
  停用不删除证书和使用记录。
- **录入证书**：器具必须已登记；日期必须为 YYYY-MM-DD 且实际存在，校准日期不能晚于本机今天，
  截止日必须晚于校准日期；测得误差必须是有限数；编号、方法、摘要不能留空。
  是否超差由系统按 `|测得误差|` 与器具允许误差比较得出（等于限值算合格），录入者不能自行选择结论。
- **证书编号**：全台账唯一。同号且业务字段完全一致时返回原证书、不增加历史；
  同号内容冲突时报冲突且不改动已有数据。
- **最近证书**：按校准日期确定，与录入先后无关；补录较早证书只增加历史。
  同一器具同一天不接受两张不同编号的证书。最近证书超差或到期时，不回退到更早的合格证书。
- **到期判定**：有效期截止日当天起即到期；每次查询和申请使用都按本机当前日期重新判断。
- **使用申请**：只有在用状态、最近证书合格且未到期的器具才能获准；
  停用、待校准、没有证书、超差或到期都会被拒绝，并列出全部适用原因。
  每次申请都保存申请时间、允许或拒绝的结果和当时原因；未知编号明确报错且不新增记录。
- **按器具核对**：展示登记信息、当前能否使用及原因、最近证书与到期日、
  全部历史证书和被拒绝的使用记录；历史拒绝原因不随后续补录证书或切换状态而改变。
- **持久化**：每次变更通过临时文件 + 原子重命名保存，无效录入不会留下半份记录；
  重新打开台账后按保存的记录与打开时的本机日期给出结果。
