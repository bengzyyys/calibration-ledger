# 本地器具校准与证书台账

在本机运行的器具校准台账：登记器具、录入校准证书、申请使用器具、按器具核对结果、
安排校准计划。数据只保存在用户指定的本机文件中，不连接任何真实实验室；退出后
再次打开同一台账可继续查询与操作，不同台账文件之间的数据互不混入。

## 构建与测试

```bash
go test ./...
go build ./cmd/ledger
```

原有的 `calibrate.Ready()` 公开入口保持不变。

## 命令行用法

所有子命令都通过 `-f/--file` 指定台账文件（默认当前目录 `ledger.json`），
加 `--json` 可输出机器可读结果。退出码：`0` 成功；`1` 业务拒绝或编号不存在；
`2` 参数或文件读写错误。

```bash
# 登记器具：编号、名称不能为空；允许的绝对误差必须是不小于零的有限数。
# 新器具自动处于“待校准”状态，编号重复会被拒绝。
ledger -f 我的台账.json register --id M-001 --name 数字万用表 --allowed 0.5

# 切换状态：在用、停用、待校准。切换为在用不代表已校准；停用不删除证书与使用记录。
ledger -f 我的台账.json status --id M-001 --status 在用

# 录入证书：日期必须是实际存在的 YYYY-MM-DD；校准日期不能晚于本机今天；
# 截止日必须晚于校准日期。证书编号全台账唯一。
ledger -f 我的台账.json cert \
  --instrument M-001 --number C-2026-01 \
  --cal-date 2026-09-01 --expiry 2027-09-01 \
  --method JJF规范 --error -0.4 --summary 例行校准

# 申请使用：只有“在用 + 最近证书合格 + 未到期”才允许；拒绝时列出全部原因。
# 无论允许还是拒绝都会留痕；未知编号报错且不留痕。
ledger -f 我的台账.json use --id M-001

# 按器具核对：登记信息、当前能否使用及原因、最近证书、全部历史证书、
# 被拒绝记录、当前计划与已结束计划（含改期记录和关联证书编号）。
ledger -f 我的台账.json review --id M-001

# 列出全部器具
ledger -f 我的台账.json list

# 建立校准计划：计划编号全台账唯一（计划结束后也不能重复使用）；
# 计划日期必须是实际存在的 YYYY-MM-DD 且不早于本机今天；说明非空。
# 每件器具最多有一项未完成、未取消的计划。
ledger -f 我的台账.json plan create \
  --instrument M-001 --number P-2026-01 --date 2026-10-20 --description 年度校准

# 改期：新日期不能早于操作当天，必须填写非空原因；保留每次修改前后的
# 日期、操作时间和原因。已完成或已取消的计划不能改期。
ledger -f 我的台账.json plan reschedule \
  --number P-2026-01 --date 2026-10-25 --reason 延期一周

# 取消：必须填写非空原因；取消后保留原计划日期、取消时间和原因，
# 不再列入待办。已完成或已取消的计划不能取消。
ledger -f 我的台账.json plan cancel --number P-2026-01 --reason 设备故障

# 完成：指定一张台账中已有的证书。证书必须属于该器具，校准日期不得早于
# 计划最初建立日期，且不能已用于完成其他计划。超差证书也能完成计划，
# 但器具是否可用仍按现有状态、最近证书结论和有效期判断。
ledger -f 我的台账.json plan complete --number P-2026-01 --certificate C-2026-01

# 待办查询：默认列出全部未结束计划，也可按器具编号筛选；按计划日期由早到晚
# 排列，同日按器具编号排列。计划日为今天的标“今天需校准”，已过的标“逾期”，
# 未来的标“未到计划日”；标记每次查询按本机日期重新判断，查询不留痕。
ledger -f 我的台账.json plan todos
ledger -f 我的台账.json plan todos --instrument M-001
```

## 判定规则

- **合格 / 超差**：由测得误差的绝对值与器具允许误差自动比较，等于限值算合格，
  超过限值明确显示“超差”，录入者不能自行选择结论。
- **最近证书**：按校准日期确定，与录入先后无关；补录较早证书只增加历史。
  最近证书超差或到期时，不会回退到更早的合格证书。
- **到期**：有效期截止日当天起即到期；每次查询和申请都按本机当前日期重新判断。
- **同号证书**：同号且全部业务字段一致时返回原证书、不增加历史；
  同号内容不同报冲突且不改动已有数据。
- **同日限制**：同一器具同一天不接受两张不同编号的证书。
- **历史冻结**：使用申请被拒绝时记录申请时间、结果与当时全部原因；
  之后补录证书或切换状态都不会改写历史拒绝原因。
- **计划编号终身唯一**：计划编号即使对应已结束（已完成或已取消）的计划也不能
  重复使用；每件器具最多有一项未完成、未取消的计划。
- **计划日期底线**：建立与改期时，计划日期都不能早于操作当天（本机日历日期）。
- **改期留痕**：每次改期都保留修改前后的日期、操作时间和原因；取消保留原计划
  日期、取消时间和原因；完成保留完成时间和关联证书编号。
- **完成条件**：用于完成计划的证书必须属于该器具，校准日期不得早于计划最初
  建立日期，且不能已用于完成其他计划。再次用同一证书完成同一计划返回原结果，
  不增加记录或刷新完成时间。
- **计划不替代判定**：超差证书也能表示校准工作已完成，但器具是否可用仍按现有
  状态、最近证书结论和有效期判断；计划本身不改变允许误差或证书。
- **停用不取消计划**：停用器具不会自动取消计划，仍可查询和处理它的计划。
- **无半份记录**：任何无效录入都在写盘前被拒绝，台账文件采用临时文件原子替换。
